# MasterGraduateWork
This repository contains the source code and research materials for a Master's dissertation focused on enhancing market basket analysis and product recommendation systems. The project introduces an automated pipeline for semantic product grouping using modern NLP techniques and spatial modeling, including SBERT embeddings, PCA, UMAP, and HDBSCAN clustering. By combining the CHARM algorithm with a custom multilevel semantic filter, the solution effectively addresses the common "rule explosion" problem, filtering out redundant associations to isolate highly significant cross-category connections.

Furthermore, the repository includes the implementation of a custom ranking metric designed to overcome popularity bias. This ensures that valuable, niche product relationships are prioritized over trivial, mass-demand rules. The project culminates in an interactive web application that provides e-commerce businesses and retail analysts with actionable tools to explore topological macroanalysis of association rules, ultimately helping to optimize cross-selling strategies and spatial store layouts.

The .parquet files contain the generated association rules derived from the Instacart dataset, available in both mono-rule (single item on each side) and multi-rule (multiple items on the left or right sides) formats. These datasets are structured across four distinct filtration levels to demonstrate the effectiveness of the semantic filter. Level 0 represents the raw rules without any filtration applied. Level 1 applies baseline filtration using standard product categories (aisles). Level 2 incorporates both standard categories and the generated SBERT/HDBSCAN clusters. Finally, Level 3 provides the most rigorous filtration by combining standard categories, clusters, and broad product departments.

The Market_Basket_Analysis_Methods.ipynb notebook serves as the primary research document of the project. It encompasses the entire analytical pipeline, detailing every step from initial data loading and text preprocessing, through the application of NLP and dimensionality reduction techniques, to the final extraction and evaluation of the association rules using the CHARM algorithm.

The app.py script contains the source code for an interactive web dashboard. This application is specifically designed to demonstrate various visual techniques for exploring the extracted association rules, allowing users to dynamically interact with the data and analyze cross-category relationships in real-time.

The api.py file provides a dedicated API implementation. This component is built to facilitate the seamless integration of the developed recommendation models, custom metrics, and semantic filtering mechanisms into external e-commerce platforms or existing software ecosystems.
